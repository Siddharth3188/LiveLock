# Contributing

1. Open an issue first for larger changes.
2. Keep Windows-specific code in the App project; keep logic testable in `LiveLock.Core`.
3. Add tests for Core logic. Run `dotnet test tests/LiveLock.Core.Tests`.
4. Don't add copyrighted media or Apple assets. Use original or properly licensed files.
5. Be honest in docs: never describe a feature as working unless it was verified.
